DAILY CHRISTIAN PRAYER — ONE-LINK WEBSITE

This folder contains the entire universal prayer site. It is NOT live until you publish it.

PUBLISH WITH GITHUB PAGES (no credit card or paid hosting package necessary):
1. Sign in / create a free account at https://github.com
2. Create a new PUBLIC repository, e.g. daily-christian-prayer.
3. Upload all the files from this folder into the ROOT of the repository (not the ZIP itself).
4. Open Settings > Pages > Build and deployment. Select Deploy from a branch.
5. Choose main branch and /(root), then Save.
6. GitHub will show your live site link when publishing is complete. It normally looks like:
   https://YOUR-USERNAME.github.io/daily-christian-prayer/
   Do not share the example address; copy your actual URL from GitHub Pages.
7. On your Samsung or iPhone, open the live address in Chrome or Safari and use the “Save to Home Screen — How to” help.

GITHUB PAGES NOTES:
- GitHub's rules allow some donation buttons, but do not allow using Pages primarily for an online business/e-commerce site. This app is prayer-first with an optional donation link.
- Public repository means source code and prayer content are publicly visible. Do not put secrets in these files.
- The free tier has usage limits; no website can guarantee availability forever.
- Opening the live website will NOT automatically migrate a name saved in the former local HTML file. People will enter names once at the published URL.
- After the first connected visit, the app caches itself for offline reading on supported browsers. PayPal and Facebook still require internet.
- The payment page is external; no payment details are collected by the prayer app.
- On iOS, open with Safari to use Add to Home Screen. On Android, use Chrome or Samsung Internet.
- Keep this ZIP as your backup. Never delete the repository while you want the public link working.

HOW TO CHANGE CONTENT: edit index.html in your repository; changes will publish again.
